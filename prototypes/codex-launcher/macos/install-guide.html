GatherThread Launcher
拖入“应用程序”，再连接 Codex

  1. 将 GatherThread Launcher.app 拖到旁边的 Applications（应用程序）。从“应用程序”中首次打开，不要直接在此安装镜像中运行。
  2. 若 macOS 阻止打开：核对官方安装包后，进入 系统设置 → 隐私与安全性 → 仍要打开，再按系统提示确认。
  3. 先登录 GatherThread 网页，进入项目并点击“连接 Codex → 打开启动器”。核对自动填入的邮箱和正式 / 测试环境，只在启动器输入密码。安装插件后，重启 Codex，并审查、信任并允许共序 Hooks，才会同步直接在 Codex 发送的回合。保持启动器运行。

当前安装包仅临时签名，尚未通过 Apple 公证。仅在核对官方来源和校验和后使用“仍要打开”；不要绕过不可信程序的警告。替换已有应用前，先停止旧启动器。安装不会要求 sudo 或关闭系统安全保护。

Install once. Connect from the website.

  1. Drag GatherThread Launcher.app onto Applications. Open it from Applications once; do not run it from this disk image.
  2. If macOS blocks it, first check the official download, then open System Settings → Privacy & Security → Open Anyway and confirm the system prompt.
  3. Sign in to GatherThread, open your project and choose “Connect Codex → Open Launcher”. Check the prefilled email and production/test environment, then enter your password only in the Launcher. After installing the plugin, restart Codex and review, trust and allow GatherThread Hooks before syncing direct Codex turns. Keep the Launcher running.

This app is ad-hoc signed, not Developer ID signed or Apple-notarized. Use Open Anyway only for the verified official package. Stop an older Launcher before replacing it. Installation does not require sudo, disabling Gatekeeper or removing quarantine.
