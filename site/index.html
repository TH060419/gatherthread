[ HARNESS-NEUTRAL ]

不绑定具体 Agent harness。

每位协作者都可以保留自己熟悉的本地 Agent 和工作方式。回复会标注用户名、harness、provider、模型和上下文保真度，不会向其他成员暴露本地设备或原生会话标识。

[ SESSIONS ]

两种会话：solo 与 multi。

[ SOLO ]

Solo · 个人会话

由创建者发布完整的规范化会话事件流；项目内其他所有人只读，即使对方是项目创建者。

[ MULTI ]

Multi · 协作会话

多人共享一个有序的项目会话。普通聊天消息只进入共享会话，不会调用 Agent；Agent 请求只由发送者自己的本地 runtime 领取。

[ COMPLETE CONTEXT ]

三种上下文保真度。

根据历史重建的上下文绝不会被标记为 provider_request；上下文压缩由每个本地 Agent 自行处理，共享的规范事件日志保持完整和持久。

[ CANONICAL_HISTORY ]

规范历史

该成员可见的完整共享事件历史。服务器以 SQLite WAL 持久化只追加的规范事件日志，为每个会话分配权威序号。

[ HARNESS_TRANSCRIPT ]

Harness 转录

从已授权的本地 harness 会话记录中实际观察到的内容，经解析与脱敏后进入共享历史。

[ PROVIDER_REQUEST ]

Provider 请求

由明确授权的 harness hook 或 provider 代理观察到的原始请求。未获明确授权并确认前，一律不上传。

有序 · 可追溯 · 实时同步

连接本地 Agent

在项目中连接自己的 Codex 或 DeepSeek Harness。模型、凭据和本地文件继续由本人管理。

查看连接指南 ↗

[ SETUP ]

连接你熟悉的 Agent。

[ CODEX ]

  1. 一次性安装固定版本的「共序 / GatherThread」Codex 插件。
  2. 复制网页生成的 macOS / Linux 或 PowerShell 连接命令。
  3. 重启 Codex Desktop，审查并启用插件 Hooks，然后保持连接器终端运行。

[ DEEPSEEK HARNESS ]

  1. 把 @gatherthread/dsh-host 安装到已验证的 DSH Web profile。
  2. 启动 dsh web 并保持运行。
  3. 打开 Settings → GatherThread / 共序，输入当前服务器地址，并批准一次性配对码。
  4. 选择 Provider 和 Model，确认连接后即可在项目中使用。

[ CLOUD GIT · OPT-IN ]

需要代码协作时，再开启云端 Git。

云端 Git 只用于同项目成员协作，不用于 GatherThread 产品开发或其他用途。项目内所有成员可查看已同步的分支，包括 Solo 会话相关代码。

[ YOUR CHOICE ]

上传由你决定

项目创建者先启用云端仓库；每位成员再分别授权自己的本地目录。自动代码上传默认关闭，也可暂停云端同步。

[ LOCAL FIRST ]

本地 Git 仍归你所有

云端代码可在设置中按权限清理，不会删除你的本地 Git；关闭云端同步后，代码云端协作会受限。

[ SECURITY ]

安全机制与当前限制。

设备凭据

使用 pepper 保护的设备凭据，只完整展示一次。

可撤销会话

仅存 HMAC 摘要且可撤销的浏览器会话。

一次性授权

一次性邀请与设备授权，用完即废。

实时连接 ticket

30 秒有效、一次性、限定会话。

访问控制

solo / multi ACL 与基于角色的访问控制。

事件脱敏

不暴露本地设备或原生会话标识。

限流与配额

按设备限流，事件与快照任务存储配额。

备份与恢复

SQLite 备份 / 恢复脚本开箱即用。
