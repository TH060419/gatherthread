隐私说明

共序为邀请制 Alpha 协作服务。以下说明适用于官方服务；自托管实例的运营者应公布自己的存储位置、备份和日志保留安排。

我们处理什么

为提供协作服务，我们保存账号显示名、设备名称和凭据摘要、项目成员关系、共享会话消息与 Agent 输出、可选上传的云端 Git 代码检查点，以及必要的安全与运行日志。设备访问 Token 不以明文保存在服务端。你本地 Codex / DeepSeek Harness 的文件、原生会话和模型凭据不会因为登录而自动上传；连接器或插件只按你启用的功能上传选定内容。

项目成员可见范围

项目成员可以读取该项目的共享会话历史和已上传的云端代码；Solo 限制其他人的写入，不是私人存储。请勿上传不愿与项目成员分享的秘密信息。共享 Multi 消息及代码中由用户自行输入的姓名或其他识别信息，不会因为账号注销而被自动改写。

注销账号

可在工作页面“设置 → 账号与隐私”自行注销。须先把拥有的项目移交给现有参与者，或删除这些项目，并处理个人云端代码分支。注销前页面会显示即将删除的 Solo 云端会话数量。确认后，Solo 云端会话被删除，设备凭据、登录状态和成员关联被撤销；Multi 的共享记录继续保留，但服务端作者账号关联改为“已注销成员”。本地 Agent 会话、工作目录和设备文件不会由共序远程删除。

删除后的保留期限

在线服务在注销事务完成后立即停止提供被删除的 Solo 会话和账号数据。包含已删除内容的常规备份，以及删除后不再可达的云端 Git 对象，保留最多 14 天；含用户标识的常规运行与安全日志保留最多 30 天。期限从对应数据删除或日志产生之日起计算。备份只用于灾难恢复，不作为普通会话访问；恢复旧备份时必须重新应用期间的注销与删除记录，不能使已删除账号重新上线。

共享 Multi 内容、仍可从项目代码主线或其他成员分支到达的 Git 对象，不属于“删除后不再可达”的数据，会随项目继续保留。Git 提交元数据可能保留原作者显示名；账号注销不重写共享 Git 历史。用户自己导出的副本、其他成员的本地副本、第三方 Agent / 模型服务中的数据不受共序服务器清理控制。如依法需要保全证据，可能需延长个别受限副本的保留，并应单独记录和告知适用范围。

联系

隐私或注销问题请发送至 coolhezi@sjtu.edu.cn。不要在公开 Issue 中粘贴 Token、邀请密钥、私人聊天或代码。

Privacy notice

GatherThread is an invitation-only Alpha collaboration service. This notice applies to the official service. Self-hosted operators should publish their own storage, backup and log-retention practices.

What we process

To provide collaboration, we store account display names, device names and credential digests, project memberships, shared conversation and Agent output, optional cloud Git checkpoints, and necessary security and operational logs. Device access tokens are not stored in plaintext on the server. Signing in does not automatically upload local Codex / DeepSeek Harness files, native conversations or model credentials; connectors and plugins upload selected content only for features you enable.

What project members can see

Project members can read that project's shared conversation history and uploaded cloud code. Solo restricts others' writing; it is not private storage. Do not upload secrets you do not want project members to see. A user's name or other identifying information written into shared Multi content or code is not automatically rewritten when that account is deleted.

Delete your account

Use “Settings → Account & privacy” in the workspace. First transfer every project you own to an existing participant or delete it, and resolve personal cloud code branches. The page previews how many Solo cloud conversations will be deleted. After confirmation, Solo cloud conversations are deleted, device credentials, sessions and membership links are revoked, and shared Multi records remain with their server-side author account association changed to “Deleted member”. GatherThread does not remotely delete local Agent conversations, workspaces or files.

Retention after deletion

The live service stops serving deleted Solo conversations and account data immediately after the deletion transaction. Routine backups containing deleted material, and cloud Git objects that become unreachable after deletion, are retained for no more than 14 days; routine operational and security logs containing user identifiers are retained for no more than 30 days. The clock starts when the relevant data is deleted or the log is created. Backups are used only for disaster recovery, not ordinary conversation access; restoring an older backup must reapply subsequent account and content deletions before serving users.

Shared Multi content and Git objects still reachable from a project's main line or another member's branch are not “unreachable after deletion” and remain with the project. Git commit metadata may retain the original author's display name; account deletion does not rewrite shared Git history. User exports, other members' local copies and data held by third-party Agents or model providers are outside the GatherThread server's deletion control. If evidence must be preserved by law, an individual restricted copy may need a longer retention period, with its scope separately recorded and disclosed.

Contact

For privacy or deletion questions, email coolhezi@sjtu.edu.cn. Do not post tokens, invitation secrets, private chats or code in public issues.
