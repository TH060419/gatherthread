# 试用云端 Agent

平台体验模型和个人 API 都从同一个云端 Agent 入口使用，可用模型、额度与状态以工作页显示为准。自托管的模型和运行环境配置见[管理员指南](HOSTED_AGENT.md)。

选择云端 Agent，说清楚想做的小任务，回答会留在同一段共享会话中。不需要安装本地 Agent；使用平台体验模型无需自己的密钥，也可在设置添加个人 API。可用模型、使用额度与服务状态以工作页显示为准。

## 第一次做个小任务

1. 登录 GatherThread，进入一个允许你发言的项目会话。访客只能阅读，不能发起 Agent 请求。
2. 打开消息框旁的 Agent 选项，选择 **云端 Agent** 和模型，写下一个明确的小任务，例如“新建一个 `hello.txt` 文件，写入一行问候语，然后确认文件内容”。如果之前隐藏了云端 Agent，可在 **设置 → 可用 Agent** 中启用。
3. **使用 GT Cloud 代码，改动保存到我的 GT Cloud 分支**默认开启，并记住当前账号在这个项目的选择；发送后不会自动关闭。GT Cloud 文件共享已启用且有写权限时，项目代码会发送给模型，符合规则的改动保存到你的分支；首次运行可从共享版本开始。只想在空的临时工作区试用时可关闭，关闭的选择也会保留。共享暂停或无写权限时不会发送项目代码。这个选项不读取独立的本地或 GitHub 文件。
4. 点击 **请求我的 Agent**，阅读确认提示。Agent 会在隔离容器中使用 OpenCode 读写文件、运行终端命令，并通过服务器的模型代理获取回答。完成后，答复进入当前会话。
5. 勾选了项目云端代码时，符合规则的改动会保存到你自己的云端分支。打开右侧 **文件 → GT Cloud → 我的分支** 即可查看，无需电脑 Agent 在线。共享 `main` 仍需项目创建者审核合并；本地文件不会自动改变。

## 使用前了解

以下说明适用于临时工作区和 GT Cloud 代码任务；GitHub 仓库任务采用文末链接中的独立流程与限制。

- 你的请求和当前会话的一小段共享上下文会发送到你所选的模型服务商。勾选项目云端代码后，所选代码也会进入模型请求。不要输入不愿意交给该服务商处理的内容。
- 每次运行是新的临时环境，结束即清理。未勾选代码选项时，Agent 创建的文件不会保存。
- 云端容器带有 Python 3、Node.js 和 Git，没有通用外网访问，不能在线下载依赖。每次最多处理约 100 个文件、500 KiB 代码与 12 KiB 会话上下文，单轮最长 12 分钟。较大的项目或需要联网安装依赖时，请连接自己的本地 Agent。
- 普通聊天不会调用 Agent。本地 Agent 请求仍由你的本地设备处理；云端体验使用同一个 Agent 选择器和发送按钮。
- 默认每位用户同时运行一个任务，两次启动至少间隔 30 秒；换项目、模型或设备共用同一限制。当前任务未完成或仍在冷却时，状态栏会提示原因。工作页显示的每日额度以及服务商与服务器的并发限制也适用。
- 设置和输入区会显示所选服务商和模型；管理员配置了每日限额时，才显示剩余次数。模型忙碌或服务商暂时不可用时，不会自动换成别的模型。API Key 由管理员配置，使用者无需自行填写。若提示运行服务不可用，请联系管理员。
- 云端体验运行时，同一个请求按钮会变为 **暂停 Agent**，暂停后可 **继续 Agent**。继续会使用更新后的共享历史和原模型发起新请求，并非恢复旧运行的精确断点；未发送草稿保留。失败回答可点击 **重试 Agent 请求**，繁忙或冷却时需稍等。
- 可用摘要按钮选取已完成的消息，由当前云端或本地 Agent 生成共享摘要。云端摘要只发送选中消息与摘要提示，不发送项目文件；原文保留，无须安装本地 Agent。

## 使用个人 API

1. 打开 **设置 → 个人 API → 添加 API**，选择服务商，填写连接名称、准确的模型 ID 和密钥。保存不会调用模型或产生测试费用。
2. 在输入框旁的 Agent 选项中选择 **云端 Agent** 和刚保存的模型，再发送请求。也可用于共享摘要；符合条件的模型可用于已授权的 GitHub 仓库任务。
3. 密钥仅供本人账号使用，服务器加密保存、不会回显。编辑时留空保留原密钥；更换服务商须填新密钥。暂停或删除连接会停止使用它的运行任务。旧请求的重试和继续锁定原配置，配置变更后需重新选择并发起新请求，不会悄悄替换模型或付款账号。

支持通义千问（百炼中国）、GLM（智谱 BigModel）、豆包（火山方舟中国）、OpenAI、Anthropic、DeepSeek、硅基流动中国/国际与 OpenRouter 的固定官方接口。预设提供填写示例，请填写自己账号可用且支持工具调用的准确模型或接入点 ID。不支持自定义地址或任意请求头。费用由服务商向你的账号收取，请同时设置其消费上限。个人 API 每账号每日最多接受 100 次任务，整个服务器每日最多 1,000 次；共享服务器的并发、资源、运行时长等限制仍适用，不使用平台体验模型的免费额度。具体可用性以工作页为准。


服务器管理员的构建、配额与凭据配置见[运维指南](HOSTED_AGENT.md)。

## GitHub 云端项目

电脑直连 GitHub 的文件同步可在 **项目文件协作 → GitHub** 中独立使用。Beta 2 也开放其中的云端仓库任务入口；运行时需要独立启用 GitHub 服务、授权 App，并配置合适的编码模型。小型 Cloudflare 体验配置不支持仓库任务，其他模型仍需实际编码与资源验收。使用流程、已存任务审核、限制和管理员配置见 [GitHub 云端工作区](HOSTED_GITHUB.md)。

## 超时后继续

云端请求单轮最长 12 分钟。处理超时与其他失败会分别显示；超时结果提供“继续”。点击后，系统使用原任务、原模型、最新共享对话与已保存的云端代码（原请求选择了代码时），启动新一轮最多 12 分钟的请求，仍计入正常配额。重复的原任务文本在续接上下文中只提供一次；不同的共享消息和公开结果保留，并仍受原上下文大小限制。已终止进程的私有思考、未保存文件及运行中的命令无法原样恢复。

摘要超时后继续会保留原消息选择和总结指令，不额外发送未选中的对话或项目代码。GitHub 仓库任务的“继续任务”从已保存的源码快照开始，不恢复原进程。
