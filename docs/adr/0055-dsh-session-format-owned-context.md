# ADR-0055: Versioned DSH Session attribution and owned context

- Status: proposed / compatibility review
- Date: 2026-10-13

## Context

Native DSH 0.2.0-rc.2 uses Session format 4. Its public append boundary refuses
generic `kind:"plugin"` sources and positional replacement with `start/end`.
GatherThread uses both for quoted collaboration history and isolated execution
context, including durable ownership and author-erasure retirement markers.

## Decision

Select attribution and surface fields from the target Session's explicit format
version. Keep format 2/3 producers and persisted identity unchanged; format 4
uses the GatherThread-owned producer kind. Recognize the exact third-party
identity generated by upstream's v3-to-v4 migration when checking ownership and
retirement. Unknown explicit versions refuse writes instead of guessing.
The concrete native shapes are owned by [Interface contracts](../INTERFACE_CONTRACTS.md).

The producer identity is only one part of ownership: unchanged exact message ID,
binding text, parent/workspace, live registry owner and single-writer checks must
also pass. Another producer, generic plugin wrapper or local manual input cannot
authorize replacement or execution. Retirement recognition preserves the same
local-only historical conversations across native format migration.

Do not migrate or rewrite native persistence directly. Read and write only through
DSH's public Session and Agent services. Human messages remain human-attributed;
remote Agent output remains quoted user-role collaboration context and never
claims model-generated assistant or exact provider-request fidelity.

## Verification and scope

Boundary regressions cover legacy shapes, v4 append/replacement, exact migrated
ownership, conflicting producers, manual input, reconnect, deletion retirement
and refusal of future versions. The installed 0.2.0-rc.2 Session API is exercised
without opening user sessions or credentials. Isolated sdk-minimal acceptance
uses a private DSH home, read-only workspace and loopback Messages-compatible
provider to prove Codex-to-DSH delegation and parent return with ordinary and
summary contexts.

This does not claim a real DeepSeek model call, Web-profile UI acceptance or
cross-platform support for that distribution. The existing compatibility matrix
remains unchanged until its complete profile gates pass. No package version,
publication or deployment is implied.
