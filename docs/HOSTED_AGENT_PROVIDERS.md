# Hosted Agent model API options

Checked against provider documentation on 2026-09-30. Prices, quotas, available models, regional access, and terms can change. Keep every provider credential in the private server environment; users never enter an operator API key in the browser. The current source implements **Cloudflare Workers AI only**. Other choices below need a reviewed proxy adapter, quota model, privacy copy, and live tool-call test before activation.

| Choice | Fit for the first trial | Current public pricing and limit | Main decision |
|---|---|---|---|
| **Cloudflare Workers AI, Qwen3 30B A3B FP8** | Implemented default; function calling and OpenAI-compatible chat endpoint | [10,000 Neurons/day on Workers Free](https://developers.cloudflare.com/workers-ai/platform/pricing/), hard stop at the free cap. This model is listed at about $0.051/M input and $0.335/M output tokens; paid overflow is $0.011/1,000 Neurons. | Best fit for a tightly capped, small shared preview. The current configuration reserves 2,000 Neurons per request and limits global reservations to 8,000/day, so at most four requests can start per UTC day with the defaults. Confirm account eligibility and product terms before enabling. [Model details](https://developers.cloudflare.com/workers-ai/models/qwen3-30b-a3b-fp8/); [data-use policy](https://developers.cloudflare.com/workers-ai/platform/data-usage/). |
| **DeepSeek API, `deepseek-flash`** | Stronger coding-oriented scale option with tool calls and OpenAI-format API | [Published peak prices](https://api-docs.deepseek.com/quick_start/pricing/): $0.30/M uncached input and $1.20/M output; off-peak is half. No general free multi-user allocation is promised on that page. | Use a prepaid balance and explicit spend ceiling if moving beyond a tiny trial. Requires changing the fixed provider endpoint/model and replacing Neuron budgeting with token-based accounting. |
| **Gemini API, selected Flash model** | Possible low-cost alternative after privacy and region review | The [pricing page](https://ai.google.dev/gemini-api/docs/pricing) lists free and paid tiers by model. | The [terms](https://ai.google.dev/gemini-api/terms) say unpaid inputs and outputs may be used to improve Google services and reviewed by humans; they also impose age, business-use, and region conditions. Prefer a paid tier for shared project code after checking terms and availability. Requires a Gemini-specific proxy adapter and tool-call test. |
| **Groq API, a supported tool-calling model** | Fast inference alternative | [Free limits](https://console.groq.com/docs/rate-limits) are shared across the organization and depend on model; exact account limits appear in the console. | The [services agreement](https://console.groq.com/docs/legal/services-agreement) allows an integrated customer application for end users while forbidding resale of account access. Check the exact model, quota, and account terms before implementation. Requires a new proxy adapter and tool-call test. |

## What the operator needs to provide for the implemented option

1. A Cloudflare account ID and a narrowly scoped Workers AI inference API token, delivered through the server's private secret channel. Do not place the token in Git, a project, an Issue, or a chat message.
2. Confirmation that the selected account is on the intended Workers Free plan and that its Workers AI usage can be monitored. The feature flag deliberately requires this confirmation.
3. A reviewed Docker image digest from the container smoke job, plus a deployment-host smoke run. Then set the private variables in [HOSTED_AGENT.md](HOSTED_AGENT.md) and enable the flag.
4. One explicitly authorized live test with a disposable project, verifying model tool calls, terminal/file operations, quota accounting, canonical reply, and GT Cloud branch checkpoint. The automated suite uses a fake model and cannot establish live provider behavior.

The current runner has no general Internet access, so it can run only tools and dependencies already in the image or supplied source. Broader project build support needs a separately designed dependency supply path, not a model API change alone.
