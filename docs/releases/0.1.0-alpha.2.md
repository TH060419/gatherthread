# GatherThread 0.1.0-alpha.2 preview

`0.1.0-alpha.2` is the next private, pre-server-deployment preview of **共序 / GatherThread**. It retains the complete `alpha.1` collaboration, Codex, DeepSeek Harness, Web, security, and deployment feature set while tightening local Codex conversation labels and Windows release verification.

## What changed

- New managed Codex Desktop tasks use `<session> · MULTI|SOLO · GatherThread`.
- Background execution and immutable snapshot titles use the same uppercase session-type label.
- Long cloud session names are truncated before the fixed suffix, so the type and purpose remain visible.
- Snapshot completion metadata now returns the exact native thread title.
- The plugin Hook relay preserves the connector's lexical workspace key across Windows realpath aliases and drive-letter casing differences without weakening workspace containment or Hook-source checks.
- DSH release tests now validate native Windows and POSIX paths consistently.
- Web onboarding contract tests normalize checkout line endings so the same two-line install command is verified on Windows and POSIX.

Cloud and local titles remain separate display metadata. An adopted pre-existing Codex task keeps its own title, and a later cloud rename or mode change does not overwrite an existing local title. Stable project, session, native thread, and verified workspace identifiers remain the binding keys.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:8787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-alpha.2 --sparse .agents/plugins --sparse plugins/gatherthread

```

## Release gates

Run with Node.js `24.16.0`:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

The hosted GatherThread service, public registration, public Beta support, and automatic trust of Agent Hooks remain deliberately unavailable in this Alpha.
