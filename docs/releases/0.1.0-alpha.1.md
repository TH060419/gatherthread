# GatherThread 0.1.0-alpha.1 preview candidate

`0.1.0-alpha.1` is the private, pre-server-deployment preview of **共序 / GatherThread**. It is intended for maintainers and invited repository collaborators, not public Beta users.

## Ready to test

- Local-only, trusted LAN HTTPS, and private Tailscale operation.
- Project invitations, roles, Solo/Multi permissions, rename/delete controls, durable replay, and live Web updates.
- Safe Markdown, GFM tables/task lists, bundled KaTeX formulas, live public progress, and collapsed completed work logs.
- Codex Desktop connection through the standalone connector plus explicitly reviewed plugin MCP/Hooks.
- DeepSeek Harness connection through the opt-in Web-profile plugin, browser-approved pairing, all-project discovery, native editable sessions, and DSH-created cloud Solos.
- Bilingual responsive Web UI, remembered devices, accessible controls, and Safari/Chromium compatibility paths.

The future **GatherThread official service / 共序官方服务** entry is visible but disabled. Local, LAN, self-hosted, and Tailscale addresses remain usable. Alibaba Cloud deployment assets are included for the next stage but do not mean that a hosted service is online.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm install
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:8787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

## npm artifacts

Two public-scope packages are prepared but are not published by this repository change:

- `@gatherthread/codex-connect@0.1.0-alpha.1`
- `@gatherthread/dsh-host@0.1.0-alpha.1`

The matching fixed-ref Codex plugin install is:

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-alpha.1 --sparse .agents/plugins --sparse plugins/gatherthread
codex plugin add gatherthread@gatherthread
```

Build the exact candidate tarballs locally:

```bash
npm run release:pack-npm
```

Output is written to ignored `release-artifacts/npm/`. Before publishing, confirm `@gatherthread` npm scope ownership, inspect both tarballs, run `npm publish --dry-run --tag alpha` for each package, create and verify the exact private `v0.1.0-alpha.1` Git ref, then publish only with explicit maintainer approval. Both package manifests pin the `alpha` dist-tag so this preview cannot become `latest` accidentally.

## Release gates

Run with Node.js `24.16.0`:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

`release:verify` builds and tests the monorepo, checks metadata and secrets, and installs both npm tarballs from clean Git-less temporary directories. The real DSH gate uses the verified DSH Web profile and may require its package metadata cache or network access.

## Deliberately not claimed

- No public account registration or hosted GatherThread service.
- No public Beta support commitment.
- No npm publication, Git tag, server deployment, DNS, TLS certificate, or ICP filing performed by this candidate.
- No automatic installation of Codex global configuration or implicit trust of Hooks.
- No browser launch of local Agent processes.

See [Connect Codex](../CODEX_CONNECT.md), [Connect DeepSeek Harness](../DSH_CONNECT.md), and [connection modes](../CONNECTION_MODES.md).
