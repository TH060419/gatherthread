# GatherThread 0.1.0-alpha.4 preview

`0.1.0-alpha.4` is a private Alpha preview of **共序 / GatherThread** focused on recoverable Codex Desktop history visibility. It includes the Alpha 3 per-conversation upload controls and retains the complete Alpha 2 collaboration, Codex, DeepSeek Harness, Web, security, and deployment feature set.

## What changed

- Canonical cloud history can be imported into a verified native Codex Desktop task as readable conversation bubbles without running the Agent.
- Automatic visible-history import supports `first-connect` and `never`; new projects default to `first-connect`.
- The Web workspace and reviewed Codex plugin can request an experimental manual visible-history refresh.
- Empty sessions receive a local-only visibility marker, and oversized histories are compacted within the configured context budget.
- Realtime canonical delta injection remains active and independent from visible-history import.
- Codex and DeepSeek Harness retain the Alpha 3 per-conversation automatic-upload preference and idempotent manual recovery path.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:8787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

## Fixed-version integrations

- `@gatherthread/codex-connect@0.1.0-alpha.4`
- `@gatherthread/dsh-host@0.1.0-alpha.4`
- Git ref `v0.1.0-alpha.4`

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-alpha.4 --sparse .agents/plugins --sparse plugins/gatherthread
codex plugin add gatherthread@gatherthread
```

The npm packages and Git ref are separate release artifacts. Do not use the fixed Git command until the reviewed `v0.1.0-alpha.4` tag exists.

## Release gates

Run with Node.js `24.16.0`:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

The hosted GatherThread service, public registration, public Beta support, and automatic trust of Agent Hooks remain deliberately unavailable in this Alpha.

The Alpha 4 replace-in-place import path may be rejected when a prior Codex task has an active writer or is archived. Alpha 5 supersedes it with verified new-task import semantics.
