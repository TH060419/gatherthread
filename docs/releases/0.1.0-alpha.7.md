# GatherThread Alpha 7 — shared context for local AI agents and opt-in Git collaboration

`0.1.0-alpha.7` is the invitation-only hosted Alpha source at commit `52aac1a5ffda`. GatherThread connects people and their local Codex or DeepSeek Harness Agents through ordered, attributable project conversations, real-time shared context, and durable replay. Alpha 7 adds optional Git-backed project-code checkpoints and shared history summaries without replacing each person's local Agent, credentials, or workspace. The Git tag was aligned to the verified server source after the initial preview; already-published npm packages were not rebuilt by that tag move, and no Alpha 7 GitHub Release has been created. The hosted service remains invitation-only, not an open public Beta.

## What changed

- An owner may enable a server-managed Git repository per project. Every member has an attributable branch; the owner reviews and merges into shared `main`. Codex and DSH can explicitly upload eligible source checkpoints, download clean updates, or recover the last uploaded code into a new sibling directory. Automatic code upload is a separate local opt-in and defaults off. This is not a Git smart-HTTP endpoint or a backup for excluded files and unpublished edits.
- Writers may select public conversation messages or earlier summaries and ask their own connected local Agent to generate an attributed shared summary. Original events and earlier summary versions remain available. Each user's project-level derived-context preference defaults to summaries for future Web-triggered Agent requests, with an option to use original history. Summaries are lossy and never replace canonical history.
- Codex and DSH continue to use their native context and compaction behavior where supported. GatherThread keeps bounded fallback checks and fails visibly when a first import or native compaction cannot safely fit; it does not silently choose another model or discard the canonical log.
- Cross-platform Git isolation, stale-response fencing, idempotent code operations, private-path and credential checks, DSH pairing serialization, and bounded MCP input were strengthened. See [the change log](../../CHANGELOG.md) for the full audit-fix list.

## Self-hosted quick start

Use Node.js `24.16.0` and Git `2.38` or newer for code collaboration. The server may run without Git if that optional feature is never enabled.

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
git checkout v0.1.0-alpha.7
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:18787` and use the one-time owner device token shown by initialization. Review the in-app Codex or DSH instructions before installing trusted Hooks or pairing a device.

## Known limitations

- One Node.js process and one SQLite database; no automatic failover or horizontal scaling.
- Git checkpoints cover bounded eligible source files, not installed dependencies, credentials, local transcripts, or unuploaded edits. Concurrent Agents must not write the same directory; merges and downloads stop on conflicts.
- DSH compatibility is pinned to the verified npm Host `@deepseek-ai/dsh@0.1.2-rc.1`. Very large first native history imports can still exceed that Host's model context before its automatic compactor has a prior request header.
- Public registration, public Beta, automatic trust of Hooks, and a public Git remote remain unavailable in this Alpha; the hosted service is invitation-only.
