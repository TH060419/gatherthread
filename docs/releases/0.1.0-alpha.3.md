# GatherThread 0.1.0-alpha.3 preview

`0.1.0-alpha.3` is a private Alpha preview of **共序 / GatherThread** focused on explicit control of local conversation uploads and recoverable synchronization. It retains the complete `alpha.2` collaboration, Codex, DeepSeek Harness, Web, security, and deployment feature set.

## What changed

- Every bound Codex or DSH conversation now stores its own automatic-upload preference, enabled by default.
- Disabling automatic upload prevents trusted Hooks and DSH polling from publishing local turns while cloud-to-local history projection and Web Agent requests continue independently.
- Manual upload scans completed native turns and uses the existing durable, authenticated, idempotent outbox. It can recover a Codex turn even when its Hook did not run or did not leave a draft.
- Manual recovery never silently turns automatic upload back on.
- The Codex plugin exposes status, preference, and recovery through user-only MCP tools over the private local connector relay.
- DSH exposes the same preference and recovery controls in **Settings → GatherThread / 共序**.
- DSH polling and manual upload are serialized to avoid cursor or outbox races on slow transports.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:8787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

## Fixed-version integrations

- `@gatherthread/dsh-host@0.1.0-alpha.3`
- Git ref `v0.1.0-alpha.3`

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-alpha.3 --sparse .agents/plugins --sparse plugins/gatherthread
codex plugin add gatherthread@gatherthread
```

## Release gates

Run with Node.js `24.16.0`:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

The hosted GatherThread service, public registration, public Beta support, and automatic trust of Agent Hooks remain deliberately unavailable in this Alpha.
