# GatherThread 0.1.0-alpha.5 preview

`0.1.0-alpha.5` is a private Alpha preview of **共序 / GatherThread** focused on dependable Codex Desktop history visibility, explicit local-to-cloud upload control, and a maintainable multi-developer workflow. It retains the complete collaboration, Codex, DeepSeek Harness, Web, security, and deployment-preview feature set from earlier Alphas.

## What changed

- Canonical cloud history can be imported into a verified native Codex Desktop task as readable conversation bubbles without running the Agent.
- Automatic visible-history import supports `first-connect` and `never`; new projects default to `first-connect`.
- Every manual import creates a new local task. GatherThread verifies that task, then switches the durable session binding and Hook allowlist. The user reviews and archives the previous task themselves.
- Empty sessions receive a local-only visibility marker, and oversized histories are compacted within the configured context budget.
- Realtime canonical delta injection remains active and independent from visible-history import.
- Codex and DeepSeek Harness retain per-conversation automatic-upload preferences and an idempotent manual recovery path.
- The Web workspace has compact icon-only controls for both sidebars and session status, uses the top bar for project/session context, and shows Codex history/upload actions only when Codex is enabled for that project.
- Repository-wide `AGENTS.md`, contribution rules, interface-contract ownership, `CODEOWNERS`, and a PR checklist keep human and Agent changes reviewable. Every version update remains subject to project-lead review before merge or release.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:8787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

## Fixed-version integrations

- `@gatherthread/codex-connect@0.1.0-alpha.5`
- `@gatherthread/dsh-host@0.1.0-alpha.5`
- Git ref `v0.1.0-alpha.5`

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-alpha.5 --sparse .agents/plugins --sparse plugins/gatherthread
codex plugin add gatherthread@gatherthread
```

The npm packages and Git ref are separate release artifacts. Do not use the fixed Git command until the reviewed `v0.1.0-alpha.5` tag exists.

## Release gates

Run with Node.js `24.16.0`:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

The hosted GatherThread service, public registration, public Beta support, and automatic trust of Agent Hooks remain deliberately unavailable in this Alpha.
