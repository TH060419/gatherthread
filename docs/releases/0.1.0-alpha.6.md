# GatherThread 0.1.0-alpha.6 preview

`0.1.0-alpha.6` is a private Alpha preview of **共序 / GatherThread** focused on exact-runtime recovery and runtime-advertised DeepSeek Harness model selection. It retains the complete collaboration, Codex, DeepSeek Harness, Web, security, and deployment-preview feature set from earlier Alphas.

## What changed

- DeepSeek Harness runtimes may advertise the models and reasoning efforts they can actually execute. The GatherThread work page then lets the user select those values for each new Agent request instead of pinning the connection to one model and effort.
- The verified `deepseek-official` DSH integration discovers models through the Host's public LLM services and applies the selected model and reasoning effort only for the requested turn. The previous native selection is restored afterward.
- Unsupported, legacy, non-DeepSeek, or ambiguous DSH runtimes remain fixed and fail closed; GatherThread never silently routes a request to another runtime, provider, model, or reasoning effort.
- Runtime execution profiles are persisted and transported through the protocol, server, bridge, Web client, and DSH plugin with compatibility behavior for older runtimes that do not advertise profiles.
- Agent claims now use bounded lease recovery. Accepted progress renews the claim, only the recorded runtime may reclaim a lapsed attempt, and exhausted recovery produces a visible failure instead of a permanently pending request.
- A failed Agent response can be retried with its exact recorded harness, provider, model, and runtime.

## Private collaborator quick start

```bash
git clone https://github.com/TH060419/gatherthread.git
cd gatherthread
npm ci
npm run release:verify
npm run connection:local
npm run owner-host:init -- --display-name "Alice" --device-name "Alice laptop"
npm run owner-host
```

Open `http://127.0.0.1:18787` and use the one-time owner device token printed by initialization. Then follow the in-app **Connect Codex** or **Connect DeepSeek Harness** guide.

## Known limitations

- Dynamic in-workspace model and reasoning selection is enabled only when an exact compatible DSH runtime advertises those execution profiles. Other DSH providers continue to use their native fixed selection and settings.
- The verified DSH npm Host surface remains `@deepseek-ai/dsh@0.1.2-rc.1`; incompatible upstream APIs are rejected safely.
- The hosted GatherThread service, public registration, public Beta support, and automatic trust of Agent Hooks remain deliberately unavailable in this Alpha.

See [Connect Codex](../CODEX_CONNECT.md), [Connect DeepSeek Harness](../DSH_CONNECT.md), and [connection modes](../CONNECTION_MODES.md).
