# GatherThread 0.1.0-alpha.8 — invitation-only Alpha

Alpha 8 collects the changes merged after the verified Alpha 7 source. It is an invitation-only test release, not public registration or a public Beta. Source, npm packages, and hosted deployment have independent verification gates.

## Highlights

- An isolated, bilingual first-use guide and disposable example project introduce the main collaboration flow without touching real projects or credentials.
- Conversation reading now has date dividers, author-tinted bubbles, a back-to-bottom control, safer Safari text selection, quotes, and a member-mention inbox with jump-to-message navigation.
- Connected Codex and DSH runtimes advertise the models and reasoning efforts they actually support; the Web picker follows the selected runtime. Unsupported or stale profiles fail closed rather than silently switching models.
- Codex presence continues through long Agent work, while DSH preserves its independent heartbeat. Busy/thinking signals are separate from the server's Agent-claim lease. The request author can pause a queued request; continuing creates a new ordered request. This does not claim to interrupt every already-running native model turn.
- Optional Windows and macOS Codex Launcher prototypes simplify connection on the official HTTPS origin. The URI contains no credential, both Launchers validate it and require local token entry, and the manual terminal path remains available. The installers are not yet production-signed or notarized.
- Owners can issue up to 50 one-use test qualifications privately; copied project invitations include localized joining instructions and validity. Account deletion adds owner-project/branch preflight, removes Solo cloud sessions and account/device access, and retains shared Multi history with deleted-member attribution. Local files and Agent tasks are not deleted.
- ECS retention jobs and the bilingual privacy notice describe routine backups and unreachable cloud Git objects (up to 14 days), and identifying logs (up to 30 days). These operational limits must be verified on each deployment.
- Cloud Git member exit/removal, summary views, responsive dialogs, and slower Windows checkpoint writes receive compatibility and safety fixes. Alpha 7 code-sync, native context injection, per-conversation upload controls, and original-history access remain available.

See [CHANGELOG](../../CHANGELOG.md) for the detailed change list and [privacy notice](../../site/privacy/) for deletion boundaries.

## Self-hosted verification

Use Node.js `24.16.0` and Git `2.38` or newer if enabling code collaboration. In a clean checkout of the verified release source:

```bash
npm ci
npm run release:verify
npm run test:dsh-npm-plugin:real
npm run release:pack-npm
npm run release:dry-run-npm
git diff --check
```

Real Windows and macOS Launcher, Safari/Chromium workspace, DSH Host, and deployment smoke tests remain separate gates. A successful package or CI build is not a server verification.

## Hosted upgrade gate

Before upgrading `gatherthread.cn`, take and verify paired SQLite/cloud-Git backups, check the exact source archive and checksums, run the [ECS preflight](../ALIYUN_ECS.md), rehearse restore, and verify login, invitation, account handoff/deletion, two-browser replay, Codex and DSH pairing, code-sync permission boundaries, retention timers, and rollback. Keep the application on loopback behind Caddy. The operator must separately confirm the actual deployed commit and package versions.

## Known limits

- One authoritative Node.js process and SQLite database; no automatic failover or horizontal scaling.
- Cloud Git stores bounded eligible source checkpoints, not every local file or unpublished edit. It is not a public Git remote or a cross-Agent filesystem lock.
- DSH compatibility remains pinned to the verified `@deepseek-ai/dsh@0.1.2-rc.1` Host path; a very large first native import may still exceed its model context.
- Public registration, public Beta, automatic trust of Codex Hooks, and production-signed Launchers are unavailable.
