              Changes against main

              About cloud Git collaboration

              Cloud Git stores project code on this server so project members can share, review and merge it. Uploaded code is readable by every member of that project. It is used for that project's collaboration, not for developing GatherThread or other unrelated purposes. Review files for secrets before upload.

              Code upload is optional and automatic upload starts off. You can turn off cloud Git for a project; its conversations still work, but code sharing and recovery through the server are then unavailable. Turning it off alone retains existing cloud branches until they are cleared in Settings.

              Project connector

              Connect ZCode

              The connector runs Web Agent requests in a headless ZCode child inside the project workspace. Setup takes two steps.

              Alpha preview Current server only
              1. 1

                Connect this project

                Requires Node 24+ and a local ZCode installation. The device token is requested by a hidden CLI prompt.

                macOS / Linux

                Windows PowerShell
                Windows PowerShell

              2. 2

                Keep the connector running

                Every writable session registers one ZCode runtime. Web Agent requests run once in a headless ZCode child and never fall back to another harness.

              What gets synchronized?

              Shared canonical history is quoted into the headless prompt as untrusted data; public commentary and the final answer return as ordered shared events. Hidden reasoning never leaves the ZCode child.

              Local-turn capture through reviewed ZCode hooks is planned as a later phase. The connector never reads ZCode's private session store.

              This page only copies commands. No token is placed in a command, URL, or shared history.
