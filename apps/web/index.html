            Project connector

            Connect Codex

            Run one command from the root of your local GatherThread repository. It creates or reuses and opens the same-name local Desktop project , then connects every editable session with one Desktop task and one isolated background Agent runtime.

            Single-writer synchronization

            Codex Desktop exclusively owns the visible task. Web Agent requests run in an isolated background projection, and trusted hooks merge Desktop turns and the latest shared context through GatherThread.

            An owner or participant can start a new Desktop task normally. Its first submitted prompt creates and binds a personal Solo in this project; an empty task creates nothing. Viewer tasks always remain local.

            Your device token is requested by a hidden CLI prompt. It is not included in either command. After hooks are installed for the first time, open Codex Desktop Settings and enable Hooks, then review the generated .codex/hooks.json before use.
